⚖️ Trade-off & False Negative Disclosure

As mandated by rigorous thesis evaluation, local edge prefiltering introduces a measured trade-off. While reducing cloud traffic by 89.96%, subtle conversational spam lacking links, urgency, or monetary tokens increases False Negative Rate to 40.94% if background notifications rely purely on heuristics.

System Safeguard: User-initiated actions (Share-to-App and Manual Paste) bypass the local prefilter completely and route straight to the 99.19% accurate hybrid cloud engine.

Privacy Architecture & Android Constraints

Technical design principles addressing mobile operating system limitations and data minimization.

🔒

Zero Raw Retention

Incoming message text is processed in-memory during inference and immediately discarded. Only anonymized SHA-256 session tokens, numerical risk scores, and timestamps are recorded in the audit log.

📱

Android Sandboxing

Android security strictly prevents third-party apps from accessing WhatsApp or Gmail databases. ScamGuard utilizes the officially documented NotificationListenerService, processing only what is visible in the status bar preview.

⚙️

Two-Stage Efficiency

Instead of congesting cellular data networks by streaming every interpersonal chat, the Stage 1 local filter executes in 0.5ms, routing candidates to Stage 2 only when threat triggers are found.
